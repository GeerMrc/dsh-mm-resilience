# 图片解析归档复用

每张图片**首次入会时解析一次并归档**，此后所有请求不再重发图片字节——从根源避免多模态故障卡死会话。

## 设置项

- **图片像素上限**：总像素面积（宽×高），超限自动等比压缩。默认 2048×2048=DSH 官方默认。
- **每条消息解析上限**：一次输入前 N 张生成机器描述，其余仅归档。默认 20=官方上限。
- **多图解析并行数**：多图同时解析的并发数（1–8）。默认 4。

修改后点「保存」生效；值≠官方默认时字段右上角出现「恢复默认」，一键回官方值。

## 行为说明

- 贴图入会即归档：**你的消息气泡与原生 DSH 完全一致**（文字+缩略图）；机器描述以一条**默认折叠的解析记录行**呈现（官方上下文注入样式，点开查看；解析随会话当前所选模型，非多模态模型则无此行，属预期行为）。
- 原图按需回看：模型可调用 `mm_view_image` 查看归档原图（仅视觉模型路由可用）。
- 像素上限保存时会同步应用到当前全部 pi-ai 模型路由；「恢复默认」同时清除各路由覆盖。
- **总开关 = 本页右上角启停开关**：关闭后 DSH 官方行为自动接管，重新开启配置不丢。
